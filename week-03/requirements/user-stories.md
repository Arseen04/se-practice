# User stories — Smart Campus study room booking


## US-01
As a Student, I want to view which study rooms are available and when, so that I can plan my visit to the library.
**Priority:** High
**Assumption:** Availability is shown for the current day and at least the next 7 days.

## US-02
As a Student, I want to book a free room for a specific time slot, so that I have a guaranteed place to study.
**Priority:** High
**Assumption:** A student can hold only one active booking per room at a time.

## US-03
As a Student, I want to cancel a booking I made, so that I free up the room if my plans change.
**Priority:** High
**Assumption:** Cancellation is allowed any time before the booking's start time.

## US-04
As a Student, I want to receive a confirmation when I book or cancel a room, so that I have proof of my reservation.
**Priority:** Medium
**Assumption:** The confirmation is delivered through a channel already tied to the student's account; no new channel is introduced.

## US-05
As an Administrator, I want to block or unblock a room, so that students only see and book rooms that are actually usable.
**Priority:** High
**Assumption:** A blocked room is automatically excluded from availability views until it is unblocked.

## US-06
As an Administrator, I want to review room usage over a period, so that I can see which rooms are over- or under-used.
**Priority:** Medium
**Assumption:** Usage data is retained for at least the last 3 months.
